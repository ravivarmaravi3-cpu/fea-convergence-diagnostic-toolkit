# Roadmap

## V0.2: richer text parsing
- Extract load steps, substeps, iterations, timestamps, and IDs
- Store line numbers for each evidence item
- Add parser fixtures for successful and failed solves

## V0.3: multi-file correlation
- Add `ds.dat`, `.cnd`, and `.gst` adapters
- Correlate contact and element identifiers across available inputs
- Record missing-file limitations explicitly

## V0.4: dashboard
- Upload a solver directory or selected files
- Display status, warning timeline, ranked findings, and evidence
- Export a JSON/HTML diagnostic report

## V0.5: run comparison
- Compare original and revised runs
- Highlight changes in warnings, substep behavior, and diagnostic findings
